# Honours research submission

This folder contains the final report and the supporting files for the MGCLS comparison of DINOv3 and the supplied BYOL baseline in Astronomaly: Protege.

- `Kamohelo_Leriba_Honours_Report.pdf` is the report to read 
- `figures/` contains the PNG images used in the report, including the radio-source panels and discovery plot.
- `code/notebooks/` contains the analysis notebooks with their saved outputs.
- `code/feature_extraction/` contains the BYOL and DINOv3 feature-extraction modules.
- `data/` contains the saved catalogue, feature tables, Top-20 tables and discovery arrays used in the comparison.

The completed BYOL features and baseline workflow were supplied by Professor Michelle Lochner. The notebooks use paths and dependencies from the computer on which the analysis was run. The original MGCLS FITS images and pretrained DINOv3 checkpoint are not included because of their size.
